# Family Quest — Combined Demo

Godot 4.3 mobile-friendly prototype for Family Quest. The project starts at the main menu, lets the player select one of five classes and a male/female placeholder appearance, then loads the Hearthvale gameplay demo.

## Build/test
1. Import this folder into Godot 4.3.
2. Run the project.
3. Select a class and appearance, then choose Begin Adventure.
4. Test movement, attack, and interaction; talk to the Village Elder, collect three logs in the woods, and return to finish the quest.
5. Push the project to GitHub and run the included Android build workflow to generate the APK.

## Controls
- PC: WASD movement, Space attack, E interact.
- Touch: on-screen directional buttons, attack, and interact.

This is an early prototype. The included character concept art is reference artwork; in-game models are currently primitive placeholders.
